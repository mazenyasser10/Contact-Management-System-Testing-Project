# Contact-Management-System-Testing-Project
Performed software testing on a Contact Management System by creating and executing unit, integration, dynamic, and system test cases. Documented test results, identified defects, prepared execution logs, and verified key CRUD functionalities to ensure system reliability and correctness.
The testing process for the Contact Manager System was conducted using several testing
techniques and levels to ensure software quality and requirement compliance. The performed
tests helped identify defects related to validation, persistence, and functionality.
Overall, the system achieved acceptable results in most testing areas, while some issues were
identified and documented for future improvements. The testing activities contributed to
improving the reliability, usability, and maintainability of the application.
